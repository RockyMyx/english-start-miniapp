# 隐私与会员初稿：代码核查及发布前填写

核查日期：2026-09-16。范围为当前前端、后端源码；没有读取服务器私密配置或执行真实支付。
用户可读的完整初稿集中在 `config/service-documents.js`，隐私页面与会员购买弹窗展示该内容，避免维护多份不一致的条款。

## 当前确实涉及的信息

| 功能 | 处理的信息及目的 | 当前保存或外部处理 |
| --- | --- | --- |
| 微信登录 | OpenID、会话用于关联唯一学习账号、词库与会员 | 后端账号及会话记录；本机登录会话。不会自动取得头像昵称 |
| 编辑头像昵称 | 主动选择头像、使用微信昵称填写或手动输入，点击保存后用于资料展示 | 服务器头像文件与昵称，本机头像缓存；头像图片地址可被加载，不应宣称私密文件 |
| 学习目标、能力测评资料 | 每日积分目标、每周天数、年龄段、年级、接触英语时间、多选目标用于难度与建议 | 服务器及部分本机学习目标缓存；不要求姓名、完整生日、学校班级或身份证 |
| 单词练习、复习、听写、造句、对话与测评 | 词库、作答／跳过、识别文本、分数与反馈、日期、复习／签到记录用于报告与学习安排 | 服务器学习记录；部分临时操作、本日进度在本机保存。普通用户也产生学习数据 |
| 发音与语音回答 | 本次原始录音用于转写及发音评分 | 后端代码调用 Azure；结果入库，原始评测录音不写入当前后端持久化文件。平台与本机临时文件另行核查 |
| 拍照导入 | 用户拍摄的图片用于识别英文单词，确认所选词后保存 | 后端代码调用智谱视觉；原始识词照片不写入当前后端持久化文件。不是读取整个相册 |
| 语义判断 | 题目、提示、参考答案、用户答案用于判断含义 | 配置可选智谱、OpenAI 或本地规则；OpenAI 还接收内部用户ID的哈希安全标识。哈希不等于匿名化 |
| 朗读 | 单词、句子文本用于生成或取得读音 | 代码支持有道单词朗读、Azure 语音合成；前后端有音频缓存 |
| 会员支付、历史兑换 | 账号、订单／商品、金额、时长、状态、平台交易号、时间及兑换记录用于核验与售后 | 服务器订单及权益记录，实际支付渠道处理支付；应用不收集卡号、支付密码、验证码 |
| 打卡与学习报告海报 | 学习统计与窗口尺寸／像素比例用于绘图，主动保存才写入相册 | 手机海报文件；不会自动分享，不读取完整相册 |
| 客服、联系邮箱 | 主动发出的消息、问题、遮挡后的订单截图用于售后与隐私申请 | 微信原生客服／邮件渠道；复制邮箱仅写入剪贴板，不读取原有内容 |
| 通信与运行日志 | 请求时间、接口、响应状态，可能包含 IP，用于通信、安全与故障定位 | Fastify 生产日志；Nginx、云服务及备份实际规则需在部署端核查 |

未发现手机号、定位、通讯录读取或广告／统计分析 SDK。这个结论不代表“没有个人信息”。

代码依据：前端 `utils/session.js`、`pages/profile-edit`、`pages/initial-assessment`、`utils/recorder.js`、`pages/word-photo-import`、`utils/poster.js`、`utils/speech.js`；后端 `prisma/schema.prisma`、`src/app.ts`、`src/services/{image-word-recognizer,pronunciation-service,semantic-evaluator,speech-service,virtual-payment-service}.ts`。

## 微信公众平台隐私指引填写参考

下列用途可用于对应信息类型的说明，具体可选项名称以平台当前页面和接口检测为准。应用内菜单不代替平台声明与授权。

| 对应信息／权限 | 用途初稿 |
| --- | --- |
| 微信头像、昵称 | 经用户主动选择或填写并保存后，用于展示个人资料，不用于实名认证 |
| 麦克风及录音 | 经用户主动开始英语发音、造句、对话或能力测评语音回答后，录制并上传本次音频，用于语音识别、发音评分及学习反馈 |
| 摄像头、主动提供的图片 | 拍摄单词表或教材的必要单词区域，识别英文单词并由用户确认后加入个人词库；头像图片另用于资料展示 |
| 写入相册 | 用户主动保存学习打卡或报告海报时写入相册，不读取整个相册 |
| 剪贴板（如平台要求） | 用户主动复制运营者联系邮箱时写入邮箱，不读取原有剪贴板 |
| 学习资料与记录 | 保存用户选择的年龄段、年级、英语接触时间、学习目标、词库、答题及测评结果，用于复习安排、能力变化与学习报告 |
| 订单信息 | 核验会员支付状态、开通时长、处理到账异常及售后问题，不收集支付密码或银行卡号 |

运营者、联系邮箱、第三方接收的信息和用途、保存期限等须与真实运营情况一致。不要声明未使用的权限，也不要遗漏普通练习中的录音与学习记录。

## 当前会员协议所依据的权益

普通用户：导入已开放启蒙词包、已有词库管理、基础练习与复习、基础学习统计。造句和对话还受词库及题目条件限制，不应宣传为全部会员专享。

会员：新增单词、拍照识词并确认加入词库、可重复能力测评及结果／变化反馈、学习报告页面中的个性化四维报告与证据／建议。

按教材导入只是开发入口，不计入本次付费权益。源码种子和页面当前为启蒙70词，早期需求曾提50词，本次不修改词包，协议按“已开放启蒙词包，数量以页面为准”描述；部署数据库内容可能不同。

金额、天数来自后端会员商品接口；测试1元、正式99元均无需改协议。每次点击开通／续费重新弹协议，同意后创建订单；订单金额或时长变化时停止支付并要求重新确认。服务器核验支付后开通，未到期追加、已到期从支付时间计，不自动续费。到期停止会员功能，不自动删除既有学习记录。

没有应用内退款按钮，不等于一律不退款。初稿保留依法退款、支付异常及未提供约定服务的处理权利，原生客服负责受理；没有新增自动退款或应用内注销功能。

## 发布前尚需运营者确认

1. 在 `config/service.js` 补真实小程序主体名称、邮箱、可履行的客服时间与响应安排。原生客服须在微信平台开通、配置并实测可用。
2. 根据服务器实际启用配置填写第三方名称、处理数据、目的、区域、联系方式及政策链接。源码支持某服务不代表服务器正在使用；不得简单列举全部服务即视为完成告知。
3. 核查 Azure、OpenAI 及配置的代理／区域是否涉及境外处理，落实对应告知、必要同意与其他义务后再启用；不能凭 `store:false` 声称服务商不留存。
4. 设定并实际执行学习数据、账号资料、日志、备份、原始文件及订单的必要保存／删除安排。更换头像可能留下旧文件；当前删除单词／清空词库采用归档。已有服务端学习数据删除工具，但不等于完整自动注销、历史文件／备份删除均已完成。
5. 儿童资料与测评目前有监护人明确同意记录，但基础练习、录音、头像等也可能处理不满14周岁用户的信息。是否在其他儿童使用场景充分取得监护人同意，仍是发布前必须核查的事项；本次按需求不增加启动自建弹窗，不能据此认定所有儿童保护义务已完成。
6. 在微信公众平台完善并提交隐私指引，使平台声明与应用内文字一致；真机测试隐私接口的同意／拒绝、录音、拍照、保存相册、客服及会员支付。应用内阅读菜单不是授权按钮。
7. 上线前确认真实生效日期；重大隐私处理规则变化时同步更新前后端隐私版本及必要同意。会员协议版本单独维护。本初稿不保证审核通过，不替代对实际运营情况的合规核验。

- [消费者权益保护法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_0a323e046fba43f0b6e9e977f1e8d5fc.html)：重要格式条款应清楚说明，不能排除消费者法定权利；预付服务须履行约定，未履行部分依法处理。
