# 单词练练微信小程序

“单词练练”是一个原生微信小程序英语学习前端，配套后端位于
`D:\Project\english-start-backend`。当前产品采用单学习用户模型，围绕个人词库提供
单词选择、听写、造句和情景对话练习。

## 当前功能

- 首页展示今日练习次数、正确率、得分、学习时长和个人词库数量。
- 每日达标分数可设置为 1–999，默认 50 分。
- 个人词库支持手动添加、移除、清空，以及导入后端提供的启蒙词包。
- 三种选择题：听读音选中文、看中文选英文、看英文选中文。
- 单词听写：听发音后输入英文单词。
- 单词造句：根据中文情境，用文字或语音提交英文句子。
- 模拟对话：朗读英文问题，支持文字和语音回答。
- 语音回答由后端完成英文转写、语义判断和发音评分。

绘本、家长端、家庭和孩子档案目前不在本项目范围内。

## 模块开放条件与计分

开放条件由后端根据当前个人词库计算。

| 模块 | 开放条件 | 答对得分 |
| --- | --- | ---: |
| 三种选择题 | 个人词库至少 4 个词 | 1 分/题 |
| 单词听写 | 个人词库至少 1 个词 | 2 分/题 |
| 单词造句 | 个人词库至少 12 个启蒙词，且题目涉及的词已在词库中 | 5 分/题 |
| 模拟对话 | 个人词库至少 12 个启蒙词 | 2 分/题 |

导入启蒙词包会一次性导入后端当前启用的整套词汇；重复导入不会重复创建已有单词。

## 技术与目录

项目不依赖 npm 构建，使用微信小程序原生 JavaScript、WXML 和 WXSS。

```text
english-start/
├─ assets/               # 图标资源
├─ config/index.js       # API 地址与登录模式
├─ pages/                # 首页、词库及各练习页面
├─ utils/                # 请求、登录、录音、语音和学习进度工具
├─ app.js
├─ app.json
├─ app.wxss
├─ project.config.json   # 微信开发者工具项目配置
└─ README.md
```

## 本地运行

### 1. 启动后端

先按照后端仓库的 README 启动 PostgreSQL 和 API。后端默认监听
`http://localhost:3000`。

### 2. 配置小程序

API 地址统一在 `config/index.js` 中配置，当前开发版、体验版和正式版均使用服务器和真实微信登录：

```js
module.exports = {
  apiBaseUrl: "https://wx.rockyma.online",
  useDevLogin: false
};
```

- 服务器必须配置与本项目 AppID 匹配的微信 AppSecret，不要将密钥放入前端。
- 会员中心的身份切换和测评记录清空仅在 `envVersion=develop` 显示，体验版 `trial` 和
  正式版 `release` 均隐藏。无法读取环境或返回未知版本时，也隐藏开发入口。
- `NODE_ENV=production` 的后端拒绝开发身份切换、模拟登录和测评重置，不受前端显示状态影响。

### 3. 导入项目

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 在微信公众平台配置服务器合法域名；提审前在开发者工具启用合法域名校验，勿以绕过校验的预览结果验收。
4. 编译后，小程序会自动获取微信登录会话并加载首页数据。

根目录 `project.config.json` 已将仓库根目录配置为小程序源码目录，并包含当前项目的
微信 AppID。

## 登录、录音与音频

- 会话令牌保存在微信本地存储中；接口返回 401 后会清理旧令牌并自动重新登录一次。
- 当前所有版本均通过 `wx.login` 获取 code，再由后端换取微信 OpenID。
- 语音回答需要麦克风权限，录音格式为 16 kHz、单声道 WAV，单次最长 20 秒。
- 单词发音、句子朗读和对话朗读均通过后端 `/speech/tts` 获取。
- 小程序本地最多缓存 80 个语音文件，并按最近使用顺序自动清理。
- 今日学习时长记录在小程序本地；练习次数、得分、正确率和每日目标来自后端。

## 正式发布前

1. 前端已使用 HTTPS 服务器和 `useDevLogin=false`。在后端设置 `NODE_ENV=production`、
   `DEV_LOGIN_ENABLED=false`，并配置对应小程序的微信 AppID 和 AppSecret。
2. 后端 `.env` 设置 `MEMBERSHIP_PAYMENT_MODE=live`、`MEMBERSHIP_LIVE_PRICE_FEN=9900`、
   `MEMBERSHIP_LIVE_PRODUCT_ID=membership_year`、`WECHAT_VIRTUAL_PAYMENT_ENV=0`，使用现网 AppKey。
   重建API容器使配置生效，并确认该正式商品在微信现网已发布。详细步骤见后端README。
3. 在微信公众平台配置 `https://wx.rockyma.online` 的 request、uploadFile、downloadFile 合法域名，
   在开发者工具启用域名校验，真机检查图片上传、录音上传、音频下载和播放。
4. 上传为体验版后验收：无身份切换、清空测评按钮和教材导入入口，会员价99元，真实微信登录正常；
   免费用户看不到会员词库按钮，会员能完成录词、识别、测评和报告。
5. 在平台按实际使用补齐隐私指引（昵称、头像、图片、录音、学习资料及记录的使用和第三方处理说明），
   检查首次授权及拒绝授权时的流程。`app.json` 的权限说明不替代平台隐私指引。
6. 按下方“帮助、隐私与售后”补齐公开运营配置、后台隐私指引及客服人员，测试客服真机收发。
   本应用没有自助退款按钮，但仍须处理法定及支付平台受理的售后；退款后自动回收会员权益尚未实现。
   按提审页面要求填写服务类目、资质、备案状态、功能说明和审核体验方式；
   按教材导入仅为预留入口，不要当作已提供的付费权益宣传。
7. 确认前端没有数据库、微信 AppSecret、AI 或语音服务密钥。保持后端稳定，审核通过后再发布。

本地发布配置检查（测试目录已排除出小程序上传包）：

```powershell

```

## 帮助、隐私与售后

“我的”页面的帮助与服务栏目不依赖会员身份，也不依赖学习档案加载成功。
三个入口使用 `pages/service-info/index?type=privacy|membership|support`；页面不请求账号信息，
可在暂不同意学习信息处理时阅读指引或联系客服。会员页提供协议链接、默认不勾选的确认和售后入口。

### 必须填写的公开配置

集中修改 `config/service.js`，不要在其中放入任何密钥或从后端复制整份 `.env`：

| 字段 | 必须按实际填写的内容 |
| --- | --- |
| `operatorName` | 与小程序主体一致的运营者名称／姓名 |
| `contactEmail` | 实际可接收邮件的售后与隐私联系邮箱 |
| `serviceHours` | 可履行的客服服务时间 |
| `responseTime` | 可履行的预计响应时间，不要承诺即时回复 |
| `thirdPartyDetails` | 实际启用的微信、智谱、Azure、OpenAI 等服务商名称、用途、信息种类、区域、联系方式和规则；未启用的不要列为正在使用 |
| `retentionDetails` | 学习资料／结果、头像、日志、备份、订单等的实际必要保存期限、删除或匿名化安排，以及依法保留资料的限制用途 |

空项、无效邮箱会使 `serviceReady=false`：体验版与正式版不能购买或完成新的学习信息同意，
开发版可以验证流程。已有同意记录不代表平台配置已完成，仍须执行发布检查。
不要只为了通过检查填写占位文字；涉及境外处理的服务需先核实并落实对应义务。
`privacyVersion` 与后端 `PRIVACY_POLICY_VERSION` 必须一致；重要处理规则变更时同步更新并重新征求同意。
`effectiveDate` 按真实生效时间更新。价格仍读取后端配置，不在协议中写死99元。

配置就绪检查（在前端目录运行，未就绪时退出码1）：

```powershell
node -e "const c=require('./config/service'); console.log({ready:c.serviceReady,missing:c.missingFields}); if(!c.serviceReady) process.exit(1)"
```

### 学习信息及监护人同意

首次请求个人学习数据前会读取后端 `/privacy/consent`，缺少当前指引记录时打开独立同意页面。
须先打开隐私指引，明确选择本人已满14周岁或监护人，并主动勾选同意；拒绝／退出不保存同意，
相关请求停止，帮助与售后仍可进入。同意记录包含指引版本、身份及服务端时间，不是实名认证。
后端限制学习数据写入，儿童资料要求监护人身份；旧 `13+` 数据保守按须监护人同意处理，
新增 `14+` 选项区分14周岁以上用户。

微信平台默认隐私授权弹窗、相机／录音授权是独立流程。本应用未替代平台的隐私授权机制。
请在微信公众平台按实际接口补齐昵称、头像、相机／图片、录音及写入相册相关说明，
并让平台指引与应用内说明一致。按需测试同意、拒绝、取消、重新进入及权限关闭后的表现。
应用内同意不会替用户打开相机或麦克风权限；明确拒绝后不要反复弹窗诱导。

### 原生客服配置与真机验收

在小程序后台客服模块绑定可实际接待的客服人员，可绑定运营者自己的微信，
通过平台在线客服工具接待，不向用户展示个人微信号或二维码，不引导加好友、进群、领奖或私下付款。
页面使用原生 `open-type="contact"`；备用邮箱可复制。

注意：已有 `/wechat/xpay-callback` 只处理支付发货通知，不能直接复用作自建客服消息接口。
如果当前消息推送模式影响平台在线客服接待，先核查后台配置与事件日志；不要为了客服关闭支付推送，
也不要未经验证把客服事件当作支付事件响应。需要自建消息转接时须作为独立适配实现。
上传体验版后使用两个微信账号实测发起、接待、收发消息及离线联系渠道。

本次只提供人工数据申请与后端安全清理工具，不是完整自助账号注销，也未实现退款通知／自动权益回收。
删除、注销或退款的身份核验、备份处理与权益调整必须由运营者执行，不能仅靠页面文案承诺。
后端更新并完成新增数据库迁移后，再上传包含本次同意流程的前端版本。
